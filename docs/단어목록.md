# WORD TD 특수 단어 목록 (v1.0, 총 270개)

## 표 읽는 법
- **배율**: 일반 단어 스탯 공식(기획서 3-3)으로 계산한 공격력에 곱하는 값이다.
- **능력**: Lv1 기준 수치다. 레벨이 오르면 공격력은 기획서 5-1을 따르고, 능력 수치는 레벨마다 +10%씩 오른다.
- **★Lv5**: 5레벨이 되면 추가로 얻는 강화 효과다.
- **파생어**(-S, -ES, -ED, -ING, -ER, -Y, -LY 등)는 원래 단어의 능력을 물려받는다. 늘어난 글자는 기본 스탯에만 반영된다.
- 모든 단어는 실존 영단어이며, 고유명사는 없다.
