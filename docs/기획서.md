## 1. 핵심 게임 루프

1. 웨이브 시작 전 **준비 단계**에서 손패 글자 타일이 최대치까지 채워진다.
2. 플레이어는 손패 타일을 눌러(또는 PC 키보드로 입력해) **영단어를 조합**한다.
3. 단어가 사전에 있으면 **타워 카드**로 바뀌고, 맵의 빈 격자를 눌러 배치한다.
4. **웨이브 시작** 버튼을 누르면 적이 길을 따라 기지로 진격한다. 전투 중에도 단어를 만들어 배치할 수 있다.
5. 적을 처치하면 골드를 얻는다. 골드로 업그레이드, 리롤, 타일 구매를 한다.
6. 모든 웨이브를 막으면 클리어, 생명이 0이 되면 패배한다.

## 2. 글자 타일 시스템

### 2-1. 손패
| 난이도 | 손패 최대 | 웨이브당 보충 |
|---|---|---|
| 쉬움 | 10장 | 최대치까지 |
| 보통 | 8장 | 최대치까지 |
| 어려움 | 7장 | 최대치까지 |
| 지옥 | 6장 | 최대치 - 1장 |

- 타일에는 글자와 **글자 점수**(오른쪽 아래 작은 숫자)가 표시된다.
- 단어를 만들면 사용한 타일은 소모된다. 남은 타일은 다음 웨이브로 넘어간다.

### 2-2. 글자 주머니 (100장 기준 가중치)
| 글자 | 장수 | 점수 | | 글자 | 장수 | 점수 |
|---|---|---|---|---|---|---|
| E | 12 | 1 | | D | 4 | 2 |
| A | 9 | 1 | | G | 3 | 2 |
| I | 9 | 1 | | B, C, M, P | 각 2 | 3 |
| O | 8 | 1 | | F, H, V, W, Y | 각 2 | 4 |
| N, R, T | 각 6 | 1 | | K | 1 | 5 |
| L, S, U | 각 4 | 1 | | J, X | 각 1 | 8 |
| ★(만능) | 2 | 0 | | Q, Z | 각 1 | 10 |

**보정 규칙**
- 손패에 모음(A, E, I, O, U)이 항상 2장 이상 있도록 보정한다.
- Q가 나오면 U도 함께 지급한다 (QU 세트).
- 같은 글자는 손패에 최대 3장까지만 있다.
- ★ 만능 타일은 아무 글자로 쓸 수 있다. 다만 점수는 0점이다.

### 2-3. 손패 조작
| 기능 | 비용 | 설명 |
|---|---|---|
| 리롤 | 15G (사용할 때마다 +5G, 웨이브마다 초기화) | 손패 전체를 새로 뽑는다 |
| 타일 1장 버리기 | 무료 (웨이브당 2회) | 선택한 타일을 버리고 새로 뽑는다 |
| 타일 구매 | 25G | 무작위 타일 1장 (손패 최대치 초과 가능, +2장까지) |
| ★ 만능 타일 구매 | 80G | 스테이지당 2회 |
| 힌트 | 스테이지당 무료 3회, 이후 20G | 지금 손패로 만들 수 있는 단어를 최대 3개 보여 준다. 특수 단어를 우선 표시한다 |

## 3. 단어 판정

### 3-1. 사전
- **공개 도메인 영어 단어 목록(ENABLE)** 을 쓴다. 3~10글자 단어 약 10만 개다.
- 비속어나 혐오 표현은 빼고 수록한다.
- 사전은 압축 바이너리(`words.bin`)로 따로 불러오고, 해시셋으로 즉시 검색한다.
- **3글자 이상**이어야 한다.

### 3-2. 단어 종류
| 종류 | 조건 | 결과 |
|---|---|---|
| **특수 단어** | `단어목록.md`에 등록된 약 250개 | 고유 속성과 고유 능력 |
| **파생 단어** | 특수 단어 + 접미사 (S, ES, ED, ING, ER, Y, LY 등) | 원래 단어의 능력을 물려받고, 늘어난 글자 수만큼 기본 스탯이 오른다 |
| **일반 단어** | 사전에 있는 나머지 단어 | 글자 구성으로 능력이 결정된다 (3-3 참고) |
| **불가** | 사전에 없음 | 흔들림 효과와 함께 "사전에 없는 단어" 표시, 힌트 버튼이 깜빡인다 |

- 파생 단어 예시: FIRES, FIRED, FIERY는 FIRE를 계승한다. FROZEN은 그 자체로 특수 단어다.
- 처음 만든 특수 단어는 **"NEW WORD!"** 연출과 함께 도감에 등록된다.

### 3-3. 일반 단어 스탯 공식
- **L** = 글자 수, **P** = 글자 점수 합, **V** = 모음 비율 (0~1), **R** = 희귀 글자(K, J, X, Q, Z) 개수

| 스탯 | 공식 | 예시 (PLANET: L6, P10, V0.33) |
|---|---|---|
| 공격력 | `P × 3 × (1 + 0.15 × (L - 3))` | 10 × 3 × 1.45 = 43.5 |
| 공격 간격 | `1.3 - 0.6 × V` 초 | 1.1초 |
| 사거리 | `2.0 + 0.25 × (L - 3)` 타일, 최대 4 | 2.75 |
| 치명타 | `5% + 8% × R`, 피해 ×2 | 5% |

**첫 글자에 따른 공격 방식**
| 첫 글자 | 공격 방식 | 특징 |
|---|---|---|
| A ~ F | 탄환 | 단일 대상 |
| G ~ L | 관통 화살 | 일직선으로 최대 3마리 관통, 피해 70% |
| M ~ R | 포탄 | 반경 0.8타일 범위, 피해 60% |
| S ~ Z | 연사 | 공격 간격 ×0.5, 피해 45% |

- 일반 단어 타워는 회색과 흰색 계열 기본 외형에 단어 배너를 단다.

### 3-4. 특수 단어 스탯
- 기본 스탯은 위 공식을 따른다. 여기에 단어별 **배율**(0.6 ~ 1.6)과 **고유 능력**이 더해진다.
- 구체적인 값은 `단어목록.md`를 참고한다.

| 속성 | 색 | 기본 효과 | 약점 / 특이사항 |
|---|---|---|---|
| 🔥 불 | 주황 | 화상: 3초간 초당 공격력의 20% | 불 계열 적에게 50% |

| 💧 물 | 파랑 | 넉백 0.3타일, "젖음" 상태 부여 | |

| 💰 지원 | 흰금 | 공격하지 않음. 버프, 경제, 회복 담당 | |

### 4-1. 속성 연계 (원소 반응)
상태 이상이 걸린 적을 다른 속성으로 공격하면 반응이 일어난다.

| 조합 | 반응 이름 | 효과 |
|---|---|---|
| 화상 + 얼음 공격 | 증기 폭발 | 공격력 150% 범위 피해, 두 상태 모두 제거 |
| 둔화 / 빙결 + 강철 공격 | 파쇄 | 피해 ×2 |
| 젖음 + 번개 공격 | 감전 | 연쇄 +3회, 연쇄 피해 감소 없음 |
| 독 + 불 공격 | 독가스 폭발 | 독 중첩 × 공격력 30% 범위 피해 |
| 젖음 + 얼음 공격 | 빙결 | 1.5초 완전 정지 (보스 0.5초) |
| 저주 + 빛 공격 | 정화 | 피해 ×1.8 |
| 속박 + 불 공격 | 산불 | 주변 1타일에 화상 전파 |

- 반응이 일어나면 그 자리에 반응 이름이 픽셀 글씨로 떠오른다.

### 4-2. 인접 공명
- 주변 8칸에 **같은 속성** 타워가 있으면 1개당 공격력 +8%, 최대 +24%다.
- 공명 중인 타워 사이에는 얇은 빛 선이 이어진다.

## 5. 타워 성장

### 5-1. 레벨 (Lv1 ~ Lv5)
| 레벨 | 공격력 | 사거리 | 얻는 방법 |
|---|---|---|---|
| Lv1 | 100% | 100% | 배치 |
| Lv2 | 140% | 105% | 골드 업그레이드: 글자 수 × 15G |
| Lv3 | 190% | 110% | 골드 업그레이드: 글자 수 × 30G |
| Lv4 | 260% | 115% | **합성만 가능** |
| Lv5 | 350% | 125% | **합성만 가능**, 고유 능력 강화 (단어목록의 ★Lv5 효과) |

### 5-2. 합성
- 같은 단어 타워를 다른 같은 단어 타워 위로 드래그하면 합성된다.
- 결과 레벨 = 높은 쪽 레벨 + 1이다.
- 손패에서 같은 단어를 만들어 기존 타워 위에 배치해도 합성된다.
- 같은 **어근**(예: FIRE와 FIRED)끼리도 합성할 수 있다. 결과는 더 긴 단어가 된다.

### 5-3. 판매
- 그동안 쓴 골드의 60%를 돌려받는다. 타일은 돌려받지 못한다.

### 5-4. 타겟 우선순위 (타워별로 설정)
선두 / 최후미 / 최대 체력 / 최소 체력 / 가장 가까운 적 / 비행 우선

| 3. 침묵의 설원 | 눈과 얼음 | 미끄러운 얼음길(적 속도 +20% 구간) | 배트, 실드 |
| 4. 잿빛 화산 | 용암 | 입구 2개, 용암 칸(배치 불가)이 많음 | 고스트, 강화형 배트 |
| 5. 금지된 도서관 | 책장과 마법진 | 순간이동 마법진(적이 길 일부를 건너뜀), 입구 3개 | 전 종 혼합 |

### 8-2. 스테이지 규칙
- 맵마다 10스테이지가 있다.
  - 1~4: 학습과 적응
  - 5: 미니 보스
  - 6~9: 응용 (갈림길, 특수 지형 강화)
  - 10: 보스
- 웨이브 수는 `6 + 스테이지 번호`다 (7 ~ 16웨이브).
- 앞 스테이지를 클리어하면 다음 스테이지가 열린다. 앞 맵의 10스테이지를 클리어하면 다음 맵이 열린다.
- 맵 크기는 세로 화면 9 × 15칸, 가로 화면 16 × 9칸이다. 화면 방향마다 길 배치를 따로 설계한다.

### 8-3. 별점
| 별 | 조건 |
|---|---|
| ★ | 클리어 |
| ★★ | 생명 50% 이상 남기고 클리어 |
| ★★★ | 생명을 하나도 잃지 않고 클리어 |

- 난이도별로 별점을 따로 기록한다. 맵 선택 화면에 맵별 별 합계(최대 30 × 4난이도)를 표시한다.

## 9. 무한 모드

- 맵은 무작위로 생성된 길(입구 1~2개) 또는 클리어한 맵 중에서 고른다.
- 적 체력은 `1.12^웨이브`로 증가하고, 10웨이브마다 보스가 나온다 (5종 순환, 회차마다 강화).
- **5웨이브마다 유물 3개 중 1개 선택** (로그라이크 요소):

| 유물 | 효과 |
|---|---|
| 불씨 심장 | 불 속성 공격력 +25% |
| 영구 동토 | 둔화 효과 +15%p |
| 피뢰침 | 번개 연쇄 +1 |
| 맹독 주머니 | 독 최대 중첩 +3 |
| 모음 부적 | 손패에 모음 1장 추가 보장 |
| 희귀 잉크 | 희귀 글자 등장 확률 2배 |
| 긴 문장 | 6글자 이상 단어 공격력 +20% |
| 짧은 외침 | 3~4글자 단어 공격 속도 +25% |
| 이자 계약 | 웨이브 종료 시 보유 골드 5% 이자 (최대 50G) |
| 두 번째 사전 | 힌트 무제한 |
| 메아리 | 처음 배치하는 타워마다 같은 단어 Lv1 복제 1기 (1회) |
| 공명 증폭기 | 인접 공명 보너스 2배 |
| 만능 펜 | 즉시 ★ 만능 타일 2장 |
| 처형인의 낫 | 즉사 기준 10% → 15% |
| 시간 모래 | 웨이브 시작 후 5초간 모든 적 50% 둔화 |
| 견고한 성벽 | 생명 +5 |
| 원소 학자 | 원소 반응 피해 +50% |
| 백과사전 | 특수 단어 배율 +0.2 |

- **점수** = 처치 점수 + 웨이브 × 100 + 특수 단어 첫 사용 × 50 + 원소 반응 × 5
- 최고 기록(점수, 도달 웨이브, 가장 많이 쓴 단어)을 난이도별로 저장한다.

## 11. 조작

### 11-1. 단어 만들기
- **터치/마우스**: 손패 타일을 누르면 입력 슬롯에 올라가고, 슬롯의 타일을 누르면 되돌아간다. 타일을 드래그해 순서를 바꿀 수 있다.
- **PC 키보드**: 글자를 입력하면 손패에서 해당 타일이 자동으로 선택된다. 없으면 ★ 만능 타일을 쓴다. Backspace는 취소, Enter는 확정, Esc는 전체 취소다.
- 입력하는 동안 실시간으로 판정을 미리 보여 준다:
  - 회색: 사전에 없음
  - 흰색: 일반 단어
  - 속성 색 + 아이콘: 특수 단어
  - 예상 공격력, 사거리, 능력 요약을 작은 카드로 표시한다

### 11-2. 배치
- 단어를 확정하면 반투명 **미리보기 타워**가 손가락이나 마우스를 따라다닌다. 사거리 원도 함께 표시된다.
- 배치할 수 있는 칸은 초록 테두리, 불가능한 칸은 빨간 테두리로 표시한다.
- 칸을 탭하면 배치, 손패 영역으로 끌어다 놓으면 취소다.
- 모바일에서는 손가락에 가리지 않도록 미리보기를 손가락보다 1.5칸 위에 띄운다.

### 11-3. 타워 정보
- 타워를 탭하면 하단 패널에 단어, 속성, 레벨, 공격력, 사거리, 능력 설명, 타겟 설정, 업그레이드, 판매 버튼이 표시된다.
- 단축키: U 업그레이드, S 판매, T 타겟 변경

### 11-4. 게임 속도와 기타 단축키
- 속도는 ×1, ×2, ×3이다. 마지막으로 쓴 속도를 기억한다.
- 일시정지는 Space 또는 P다.

## 12. 화면 구성

### 12-1. 화면 목록
1. **타이틀**: 픽셀 로고 "WORD TD"가 글자 타일이 떨어지며 완성되는 연출. 시작, 도감, 설정 버튼.
2. **모드 선택**: 스테이지 모드, 무한 모드.
3. **맵 선택**: 맵 5개를 가로 스와이프 카드로 보여 준다. 맵별 별 합계, 잠금 표시.
4. **스테이지 선택**: 5×2 그리드, 스테이지별 별점, 보스 스테이지는 해골 아이콘.
5. **난이도 선택**: 4개 버튼과 각 난이도 수치 요약.
6. **게임 HUD** (아래 12-2 참고)
7. **일시정지 메뉴**: 계속하기, 재시작, 설정, 나가기.
8. **결과 화면**: 승리/패배, 별점 획득 연출, 처치 수, 가장 활약한 단어, 새로 발견한 단어, 재도전/다음 버튼.
9. **단어 도감**: 속성 탭 13개. 발견한 단어는 카드(능력, 최다 사용 횟수, 최고 레벨), 미발견 단어는 실루엣과 "첫 글자 + 글자 수" 힌트 (예: B _ _ _ _). 발견률을 퍼센트로 표시.
10. **설정**: BGM 볼륨, 효과음 볼륨, 진동, 피해 숫자 표시, 사거리 항상 표시, 그래픽 품질(파티클 수), 데이터 초기화, **크레딧** (영감을 받은 영상 링크, 사전 출처 ENABLE 공개 도메인, 제작 정보).

## 13. 그래픽 (픽셀아트)

- 기본 타일 크기는 16 × 16px 픽셀아트이고, 화면에 맞춰 **정수 배율**로 확대한다 (`imageSmoothingEnabled = false`).
- 32색 자체 팔레트를 쓴다.
- 스프라이트는 코드 속 문자열 도트 데이터로 정의하고, 시작할 때 오프스크린 캔버스에 한 번만 굽는다(캐싱).
- **타워 외형**: 받침대(속성 색) + 속성 아이콘(불꽃, 눈꽃 등 16px) + 아래쪽 픽셀 폰트 단어 배너 + 레벨 점(1~5개).
  - Lv4 이상은 테두리가 빛나는 애니메이션이 붙는다.
- **적**: 2~4프레임 걷기 애니메이션, 피격 시 흰색 번쩍임, 체력바.
- **이펙트**: 발사체, 폭발, 화상 불씨, 눈송이, 번개 지그재그, 독 거품, 반응 텍스트 팝업, 피해 숫자.
- **픽셀 폰트**: 영문 대문자와 숫자 5 × 7 비트맵 폰트를 자체 제작한다. 한글 UI는 시스템 폰트를 쓰되 픽셀 느낌의 테두리를 준다.
- 화면 흔들림은 보스 등장과 큰 폭발 때만 쓰고, 설정에서 끌 수 있다.

## 14. 사운드 (Web Audio 합성, 외부 음원 없음)

- **효과음**: 타일 선택(짧은 삑), 단어 확정(화음 상승), 특수 단어 발견(팡파르), 배치(쿵), 속성별 공격음 6종, 적 처치, 보스 경고, 승리, 패배.

## 16. 기술 설계

| 항목 | 방식 |
|---|---|
| 엔진 | 순수 JavaScript + Canvas 2D (외부 라이브러리 없음) |
| 렌더링 | 레이어 분리: 정적 맵 레이어는 한 번만 그리고, 동적 레이어(적, 탄, 이펙트)만 매 프레임 그림 |
| 루프 | 고정 시간 스텝(60Hz 로직) + requestAnimationFrame 렌더 |
| 최적화 | 오브젝트 풀링(탄, 파티클, 피해 숫자), 공간 격자 기반 사거리 탐색, 화면 밖 이펙트 생략 |
| 사전 | 웹 워커에서 압축 해제 후 Set 구축, 힌트 탐색도 워커에서 처리 (메인 스레드 렉 방지) |
| 반응형 | 화면 비율에 따라 세로/가로 레이아웃을 자동 전환, 기기 픽셀 비율(DPR) 대응 |
| 보안 | 우클릭, F12, Ctrl+Shift+I/J/C, Ctrl+U, Ctrl+S 차단, 개발자 도구 열림 감지, javascript-obfuscator로 난독화 |
| 원본 관리 | `src/`에 원본 코드 보관, 빌드 스크립트로 루트에 난독화본 출력 |

### 16-1. 파일 구조
```
WORDTD/
├─ index.html          # 배포용 (난독화된 game.js 로드)
├─ game.js             # 난독화 빌드 결과
├─ words.bin           # 압축 사전
├─ src/                # 원본 (유지보수용)
│  ├─ main.js, game/, render/, audio/, ui/, data/
│  └─ data/specialWords.js   # 단어목록.md를 코드화한 것
├─ tools/build.js      # 번들 + 난독화 스크립트
└─ docs/기획서.md, docs/단어목록.md
```

### 16-2. 배포
- GitHub Pages: 저장소 Settings → Pages → Branch를 `main` / root로 설정한다.
- 접속 주소: `https://0611gareddug.github.io/WORDTD/`
