# WORD TD 상세 기획서 (v3.0)

> 영단어를 조합하면 그 단어가 곧 타워가 되는 픽셀아트 타워 디펜스
> 영감을 받은 영상: https://youtube.com/shorts/XlcxdyNHKjE (설정 → 크레딧에 링크 표기)
> 타워 능력, 적, 맵, 그래픽, 사운드는 모두 독자적으로 설계·제작한다.

## 1. 핵심 게임 루프

1. 플레이어는 키보드로 영단어를 입력한다. 손패나 글자 제한은 없지만, **게임 단어 목록**에 있는 단어(와 그 파생어)만 타워가 된다.
2. 목록에 있는 단어면 **건설 비용(골드)** 이 표시되고, 목록에 없으면 **"게임에 없는 단어입니다!"** 가 뜬다. 목록 단어면 확정하면 맵의 빈 격자를 눌러 타워로 배치한다.
3. **웨이브 시작** 버튼을 누르면 적이 길을 따라 기지로 진격한다. 전투 중에도 언제든 단어를 입력해 배치할 수 있다.
4. 적을 처치하면 골드를 얻는다. 골드로 새 단어를 짓거나 기존 타워를 업그레이드한다.
5. 모든 웨이브를 막으면 클리어, 생명이 0이 되면 패배한다.

> 핵심 고민은 "어떤 단어를 쓸까"다. 길고 희귀한 글자가 많은 단어일수록 강하지만 비싸다.

## 2. 단어 입력과 건설 비용

### 2-1. 입력
- 손패나 글자 제한은 없다. 게임 단어 목록(지금 507개, 최종 1000개로 확장 예정)에 있는 단어와 그 파생어를 쓸 수 있다.
- 글자를 칠 때마다 이미 발견한 목록 단어 가운데 그 글자로 시작하는 단어를 자동 완성 후보로 보여 준다. 아직 쓴 적 없는 단어는 후보에 뜨지 않는다 (발견하는 재미 유지).
- **모바일**: 게임 전용 화면 키보드(QWERTY, 픽셀 스타일)를 화면 하단에 고정한다. 기기 키보드를 띄우지 않으므로 맵이 가려지지 않고, 한글 입력기 문제도 없다.
- **PC**: 실제 키보드로 바로 입력한다. 화면 키보드도 마우스로 누를 수 있다.
- 입력하는 동안 실시간 판정 카드가 뜬다 (11-1 참고).

### 2-2. 글자 점수
비용과 기본 스탯 계산에 쓰는 글자별 점수다. 흔한 글자는 싸고 약하며, 희귀한 글자는 비싸고 강하다.

| 점수 | 글자 |
|---|---|
| 1 | A, E, I, O, U, L, N, R, S, T |
| 2 | D, G |
| 3 | B, C, M, P |
| 4 | F, H, V, W, Y |
| 5 | K |
| 8 | J, X |
| 10 | Q, Z |

- 화면 키보드의 각 키 오른쪽 아래에 점수를 작게 표시한다.

### 2-3. 건설 비용
- **기본 공식**: `건설 비용 = (10 + 글자 점수 합 × 4) × 단어 배율 × 가격 배율`
  - 단어 배율: 단어목록의 배율과 같다 (강한 단어일수록 비쌈). 배율이 없는 지원 단어는 1.5로 계산한다.
  - 가격 배율: 기본 1. 능력을 깎지 않고 비용만으로 밸런스를 맞출 때 쓴다 (0.3~10). 지금은 테스터 제작 단어 가운데 숨은 단어 GRD만 ×2.1이다.
- **반복 할증**: 한 스테이지에서 같은 단어(같은 어근 포함)를 새로 지을 때마다 비용 +15%가 누적된다. 한 단어만 도배하지 않고 다양한 단어를 쓰도록 유도한다.
- 이미 맵에 있는 같은 단어 타워 위에 지으면 **합성**으로 처리한다 (5-2 참고).
- **난이도 배율**: 7장 표 참고.

| 예시 단어 | 글자 점수 합 | 배율 | 비용 |
|---|---|---|---|
| SUN (빛) | 1+1+1 = 3 | 1.1 | 24G |
| ROCK (대지) | 1+1+3+5 = 10 | 1.1 | 55G |
| FIRE (특수) | 4+1+1+1 = 7 | 1.0 | 38G |
| FROST (특수) | 4+1+1+1+1 = 8 | 1.1 | 46G |
| BLIZZARD (특수) | 29 | 1.5 | 189G |
| ZAP (번개) | 10+1+3 = 14 | 0.9 | 59G |

### 2-4. 단어 사전 (힌트를 대신함)
- 손패가 없으므로 "만들 수 있는 단어" 힌트는 없다. 대신 언제든 **단어 사전 패널**을 열 수 있다.
  - 발견한 특수 단어: 철자, 능력, 비용을 보여 준다. 누르면 바로 입력된다.
  - 미발견 특수 단어: 속성과 글자 수, 첫 글자만 보여 준다 (예: 🔥 F _ _ _ _).
- 특정 적 처치나 지원 단어 효과로 미발견 단어의 철자를 공개할 수 있다.

## 3. 단어 판정

### 3-1. 게임 단어 목록
- 게임 안에서 지을 수 있는 단어는 **게임 단어 목록**에 있는 단어와 그 파생어뿐이다. 큰 영어 사전은 쓰지 않는다.
- 목록은 `docs/단어목록.md`와 같은 데이터(JSON)로 관리하고, 시작할 때 Set으로 불러와 즉시 판정한다.
- **확장 계획**: 270개 → (v2.0) 501개 완료 → (v2.3) 테스터 제작 6개 추가, 507개 → 최종 1000개. SUN, CAT, BOOK처럼 누구나 떠올리는 쉬운 단어를 우선 넣어 "생각나는 단어가 거의 다 된다"는 느낌을 준다. 테스터가 크리에이터 페이지로 제출한 단어도 검토해 넣는다.
- 모든 목록 단어는 고유 능력, 고유 아이콘, 배율을 가진다.
- **테스터 제작 단어** (v2.3, 6개): ANNIHILATION(섬멸), BOOM(쾅), HOOK(갈고리), MINIGUN(미니건), SCREAM(비명), YUZUHARIKO(유즈하리코). 위키·크리에이터 타워 에디터에서 만든 값을 그대로 쓴다 (공격 방식, 공격력, 피해 종류, 공격 간격, 사거리, 범위, 효과, Lv5 강화, 직접 그린 픽셀 그림). 도감에 "테스터 제작" 표시가 붙는다. YUZUHARIKO처럼 실존 영단어가 아닌 이름도 테스터 제작 단어로는 허용한다.
- **밸런스 기준**: `전투력 = 초당 피해 × 공격 방식 계수 × √(사거리 ÷ 2.5) × (1 + 효과 가치) + 지원 가치`, `전투력 ÷ 비용`이 0.85~1.15면 적정이다. 넣기 전에 모든 테스터 제작 단어를 이 기준으로 맞췄다 (ANNIHILATION 1.00, BOOM 1.00, HOOK 1.00, MINIGUN 0.99, SCREAM 0.95, YUZUHARIKO 0.99, GRD 1.00).
- **밸런스 자동 조정** (타워 에디터): 공격력은 건드리지 않고, 고정하지 않은 값(공격 간격 0.15~15초, 효과, 범위 반경, 사거리)을 조금씩 나눠 움직여 1.00에 맞춘다. 컨셉에 필요한 값은 고정할 수 있다 (사거리는 기본 고정). 능력으로 다 못 맞추면 "가격으로 맞추기"가 가격 배율만 정한다.
- "게임에 없는 단어"로 자주 입력된 단어는 기기 안에 익명으로 기록해, 다음 확장 후보를 고를 때 참고한다.
- **3글자 이상**이어야 한다.
- **숨은 이스터에그 단어**: 실존 단어가 아니어도 제작진이 정한 비밀 단어는 예외로 둔다. 단어 목록·자동 완성·제안에는 나오지 않고, 정확히 입력해야 등장하며, 도감에는 발견한 뒤에만 표시된다. 현재: **GRD** (제작자 서명 타워, Lv5에서 화면에 "MADE BY GRD" 표시). 밸런스: 범위 3칸, 4초, 주변 강화 12%, 골드 10G/웨이브, 기절 5%, 즉사 1%, 가격 배율 ×2.1 → 210G (전투력 ÷ 비용 1.00).

### 3-2. 단어 판정
| 판정 | 조건 | 결과 |
|---|---|---|
| **타워 단어** | 게임 단어 목록에 있음 | 고유 속성, 능력, 아이콘 |
| **파생 단어** | 목록 단어 + 접미사 (S, ES, ED, ING, ER, Y, LY 등) | 원래 단어의 능력과 아이콘을 물려받고, 늘어난 글자 수만큼 기본 스탯이 오른다 |
| **게임에 없는 단어** | 목록에도 없고 파생어도 아님 | 입력창이 흔들리며 **"게임에 없는 단어입니다!"** 표시. 골드는 들지 않는다. 철자가 비슷한 목록 단어를 최대 3개 제안한다 (편집 거리, 예: FROSE → FROST, FROZE, FROZEN) |

- 파생 단어 예시: FIRES, FIRED, FIERY는 FIRE를 계승한다. FROZEN은 그 자체로 특수 단어다.
- 처음 만든 단어는 **"NEW WORD!"** 연출과 함께 도감에 등록된다.

### 3-2-1. 한국어 지원 (v2.1)
- 모든 타워 단어에 **한글 이름**이 하나씩 있다 (`docs/단어목록.md` 맨 끝 표). 한글 이름을 입력해도 영어 단어와 **같은 타워**(능력, 비용, 아이콘 동일)가 지어진다. 예: FIRE = 불, SNOW = 눈, CAT = 고양이, ANCHOR = 닻.
- **언어 설정**: 영어만 / 한글만 / 둘 다(기본). 둘 다일 때 키보드의 한/영 키로 전환한다.
- **화면 키보드**: 설정에 따라 쿼티(한글은 두벌식) 또는 천지인을 쓴다 (11-5). 한글은 누른 자음·모음을 글자로 자동 조합한다. PC는 운영체제 한글 입력기(조합 중 이벤트 포함)를 그대로 쓴다.
- **판정**: 한글 이름 목록에 있으면 타워, 없으면 "게임에 없는 단어입니다!" + 비슷한 한글 이름 3개 제안 (자모 단위 편집 거리).
- **비용·스탯**: 짝이 되는 영어 단어 기준이라 언어를 바꿔도 밸런스가 같다.
- **단어 띠**: 입력한 언어 그대로 표시한다. 한글은 오픈 라이선스 픽셀 한글 글꼴을 게임에 넣어 쓴다.
- **파생어**는 영어 전용이다 (FIRES, FIRED). 한글은 띄어쓰기만 무시한다.
- **렉시콘 보스**의 글자 봉인은 한글 모드에서 자모 2개를 봉인한다.
- 도감·단어 사전·검색은 영어와 한글 이름을 함께 보여 주고, 둘 중 무엇으로 찾아도 된다.
- 테스터 제출(크리에이터)에도 한글 이름 칸이 있고, 겹침 분석이 한글 이름 중복도 검사한다.

### 3-3. 기본 스탯 공식
모든 타워의 바탕이 되는 공식이다. 여기에 단어별 배율과 고유 능력이 더해진다 (3-4).
- **L** = 글자 수, **P** = 글자 점수 합, **V** = 모음 비율 (0~1), **R** = 희귀 글자(K, J, X, Q, Z) 개수

| 스탯 | 공식 | 예시 (STONE: L5, P5, V0.4) |
|---|---|---|
| 공격력 | `P × 3 × (1 + 0.15 × (L - 3))` | 5 × 3 × 1.3 = 19.5 |
| 공격 간격 | `1.3 - 0.6 × V` 초 | 1.06초 |
| 사거리 | `2.0 + 0.25 × (L - 3)` 타일, 최대 4 | 2.5 |
| 치명타 | `5% + 8% × R`, 피해 ×2 | 5% |

### 3-4. 단어별 스탯
- 기본 스탯은 위 공식을 따른다. 여기에 단어별 **배율**(0.6 ~ 1.6)과 **고유 능력**이 더해진다.
- 구체적인 값은 `단어목록.md`를 참고한다.

### 4-1. 속성 연계 (원소 반응)
상태 이상이 걸린 적을 다른 속성으로 공격하면 반응이 일어난다.

| 조합 | 반응 이름 | 효과 |
|---|---|---|
| 화상 + 얼음 공격 | 증기 폭발 | 공격력 150% 범위 피해, 두 상태 모두 제거 |
| 둔화 / 빙결 + 강철 공격 | 파쇄 | 피해 ×2 |
| 젖음 + 번개 공격 | 감전 | 연쇄 +3회, 연쇄 피해 감소 없음 |
| 독 + 불 공격 | 독가스 폭발 | 독 중첩 × 공격력 30% 범위 피해 |
| 젖음 + 얼음 공격 | 빙결 | 1.5초 완전 정지 (보스 0.5초) |
| 저주 + 빛 공격 | 정화 | 피해 ×1.8 |
| 속박 + 불 공격 | 산불 | 주변 1타일에 화상 전파 |
| 출혈 + 독 공격 | 감염 | 독 중첩 2배로 쌓임 |
| 유인(먹는 중) + 범위 공격 | 몰이사냥 | 범위 피해 ×1.5 |

- 반응이 일어나면 그 자리에 반응 이름이 픽셀 글씨로 떠오른다.

### 4-2. 인접 공명

## 5. 타워 성장

### 5-2. 합성
- 같은 단어 타워를 다른 같은 단어 타워 위로 드래그하면 합성된다.
- 결과 레벨 = 높은 쪽 레벨 + 1이다.
- 같은 단어를 새로 입력해 기존 타워 위에 배치해도 합성된다. 이때 비용은 그 단어의 건설 비용과 같고, 반복 할증은 붙지 않는다.
- 같은 **어근**(예: FIRE와 FIRED)끼리도 합성할 수 있다. 결과는 더 긴 단어가 된다.

### 5-3. 판매

## 11. 조작

### 11-1. 단어 입력
- **화면 키보드(모바일)**: QWERTY 3줄 + 맨 아래 줄 [지우기][사전][확정]. 키 크기는 최소 32×44px이고, 누르면 픽셀 눌림 효과와 짧은 효과음이 난다.
- **PC 키보드**: 글자 입력, Backspace 지우기, Enter 확정, Esc 전체 취소, Tab 단어 사전 열기.
- 입력하는 동안 실시간으로 판정을 미리 보여 준다:
  - 회색: 게임에 없는 단어 (비슷한 목록 단어 제안)
  - 속성 색 + 아이콘: 특수 단어
  - 예상 공격력, 사거리, 능력 요약, **건설 비용**을 작은 카드로 표시한다. 골드가 모자라면 비용이 빨갛게 표시되고 확정 버튼이 잠긴다.
- 최근 입력한 단어 5개를 입력창 옆에 칩으로 띄워 다시 누르기 쉽게 한다.

### 11-2. 배치
- 단어를 확정하면 반투명 **미리보기 타워**가 손가락이나 마우스를 따라다닌다. 사거리 원도 함께 표시된다.
- 배치할 수 있는 칸은 초록 테두리, 불가능한 칸은 빨간 테두리로 표시한다.
- 칸을 탭하면 배치, 키보드 영역으로 끌어다 놓으면 취소다.
- 모바일에서는 손가락에 가리지 않도록 미리보기를 손가락보다 1.5칸 위에 띄운다.

### 11-3. 타워 정보
- 타워를 탭하면 하단 패널에 단어, 속성, 레벨, 공격력, 사거리, 능력 설명, 타겟 설정, 업그레이드, 판매 버튼이 표시된다.
- 단축키: U 업그레이드, S 판매, T 타겟 변경

### 11-4. 게임 속도와 기타 단축키
- 속도는 ×1, ×2, ×3이다. 마지막으로 쓴 속도를 기억한다.
- 일시정지는 Space 또는 P다.

### 11-5. 모바일 키보드 설정 (쿼티 / 천지인)
- 설정 → **모바일 키보드**에서 고른다. 처음 실행 때 기기 언어가 한국어면 "어떤 키보드가 편하세요?"를 한 번 묻는다 (기본 쿼티). 판 도중 일시정지 메뉴에서도 바꿀 수 있다.

| 항목 | 쿼티 | 천지인 |
|---|---|---|
| 기본 입력 | 영문 쿼티 3줄 (키마다 글자 점수) | 한글 천지인 (ㅣ ㆍ ㅡ + 자음 6키) |
| 한/영 키 | 한글 두벌식으로 전환 | 영문 3 × 4 다중 탭으로 전환 (ABC, DEF, GHI…) |
| 키 크기 | 최소 32 × 44px | 4열 큰 키, 최소 72 × 52px (한 손 입력에 좋음) |
| 맨 아랫줄 | 지우기, 한/영, 사전, 확정 | 사전, 한/영, 띄어쓰기 대신 "다음 글자"(→), 확정 |

- **천지인 한글 규칙**: ㆍ과 ㅡ, ㅣ를 이어 눌러 모음을 만든다 (ㅣㆍ = ㅏ, ㆍㅣ = ㅓ, ㆍㅡ = ㅗ, ㅡㆍ = ㅜ, ㆍㆍ = 아래아 두 번, ㅣㆍㆍ = ㅑ …). 자음 키는 두 번 누르면 두 번째 자음, 세 번 누르면 된소리 (ㄱ → ㅋ → ㄲ).
- **천지인 영문 다중 탭**: 같은 키를 0.8초 안에 다시 누르면 다음 글자 (ABC 키: A → B → C). 같은 키의 연속 글자(예: BOOM의 OO)는 "다음 글자(→)" 키나 0.8초 기다리기로 넘긴다.
- **적 단어 표시**: 입력 언어가 한글이면 적 머리 위에 **한글 이름**(고양이, 달…)을, 영문이면 영어 단어를 띄운다. 한/영을 바꾸면 화면의 적 단어도 바로 바뀐다. 주문 단어도 한글 이름이 있다 (STOP 멈춰, RUSH 서둘러, BOOM 펑, GOLD 황금, HEAL 회복, ERASE 지우개).
- **공정성 보정**: 천지인은 한 글자에 키를 더 많이 누르므로 콤보 유지 시간 +0.8초, 적 단어는 3글자 이하 한글 이름을 우선 고른다. 쿼티 한글 두벌식은 +0.3초.
- **PC**: 실제 키보드와 운영체제 입력기를 쓰므로 이 설정은 터치 화면에서만 보인다.

## 18. 튜토리얼과 초반 경험

스토리 없이 시스템 안내만으로 진행한다. 목표는 **첫 10분 안에** 플레이어가 "아무 단어나 치면 타워가 되고, 단어에 따라 능력이 다르다"는 재미를 직접 겪게 하는 것이다.

### 첫 10분 목표

| 목표 | 측정 기준 |
|---|---|
| 단어를 직접 입력해 타워를 짓는다 | 타워 5기 이상 배치 |
| 특수 단어를 발견하는 쾌감을 느낀다 | 특수 단어 3개 이상 발견 (NEW WORD 연출) |
| 원소 반응을 한 번 본다 | 증기 폭발 1회 이상 |
| 성장 수단을 안다 | 업그레이드 1회, 합성 안내 1회 노출 |
| 첫 성공을 맛본다 | 1-1, 1-2 클리어 (실패해도 계속 진행 가능) |

### 첫 실행 흐름

1. 타이틀 화면에서 **시작**을 누르면 바로 1-1 "숲의 입구"로 들어간다. 모드·맵 선택 화면은 1-1을 깨기 전까지 건너뛴다.
2. 화면 위에 **건너뛰기** 버튼이 항상 있다. 누르면 튜토리얼 안내만 끄고 스테이지는 그대로 이어진다.
3. 튜토리얼은 설정 → **튜토리얼 다시 보기**로 언제든 다시 할 수 있다.

### 1-1 튜토리얼 단계

각 단계는 화면을 어둡게 덮고 필요한 곳만 밝게 뚫어 보여 주는 **스포트라이트** 방식이다. 안내 문구는 말풍선 없이 화면 아래 띠에 한두 줄로 띄운다. 조건을 만족하면 다음 단계로 자동으로 넘어간다.

| 단계 | 밝히는 곳 | 안내 문구 | 넘어가는 조건 |
|---|---|---|---|
| 1. 길과 기지 | 맵의 길, 입구, 기지 | 적은 이 길을 따라 기지로 옵니다. 기지에 닿으면 생명이 줄어요. | 화면 아무 곳이나 누르기 |
| 2. 첫 단어 | 화면 키보드 | 떠오르는 영단어를 입력해 보세요. 예: SUN, ICE, ROCK | 게임 단어 입력 (첫 단어는 무료). 목록에 없으면 비슷한 단어를 제안 |
| 3. 판정 카드 | 입력창의 판정 카드 | 단어마다 공격력과 비용이 달라요. 희귀한 글자가 많을수록 강하고 비쌉니다. | 확정 누르기 |
| 4. 배치 | 길 굽이 근처 빈칸 3곳 (초록 깜빡임) | 길 가까이에 지으면 더 오래 공격할 수 있어요. | 타워 배치 |
| 5. 첫 웨이브 | 웨이브 ▶ 버튼 | 준비되면 웨이브를 시작하세요. | 웨이브 1 시작 (블롭 5마리, 속도 고정 ×1) |
| 6. 특수 단어 | 키보드 + 입력창 | 어떤 단어는 특별한 힘이 있어요. FIRE를 입력해 보세요. | FIRE 배치 → NEW WORD 연출, 화상 표시 |
| 7. 골드 | 상단 골드 | 적을 잡으면 골드가 생겨요. 골드로 더 많은 단어를 지을 수 있어요. | 웨이브 2 종료 |
| 8. 업그레이드 | 이미 지은 타워 1기 | 타워를 눌러 강화해 보세요. | 업그레이드 1회 |
| 9. 원소 반응 | 입력창 | ICE를 FIRE 근처에 지어 보세요. 불타는 적을 얼리면 터집니다. | 증기 폭발 1회 (안 나면 웨이브 4 종료 시 넘어감) |
| 10. 단어 사전 | 사전 버튼 | 아직 못 찾은 특수 단어의 첫 글자를 볼 수 있어요. | 사전 열고 닫기 |
| 11. 자유 플레이 | 없음 (안내 종료) | 이제 마음껏 단어를 지어 보세요! | 웨이브 5~7 자유 진행 |

#### 1-1 안전장치

- 1-1에서는 생명이 1 아래로 내려가지 않는다. 패배 없이 끝까지 진행된다.
- 안내 중인 단계(1~10)에는 다음 웨이브가 자동으로 시작되지 않는다.
- 같은 단계에서 30초 동안 아무 입력이 없으면 밝힌 곳을 한 번 더 깜빡이고, 예시 단어를 키보드 위에 흐리게 띄운다.
- 6단계에서 FIRE 대신 다른 특수 단어를 지어도 통과한다 (NEW WORD가 뜨면 성공).

### 상황별 1회성 팁

튜토리얼이 끝난 뒤에도 처음 겪는 상황에서 한 번만 짧은 팁을 띄운다. 화면을 멈추지 않고 4초 동안 아래 띠에 보여 준다. 설정에서 끌 수 있다.

| 러너 첫 등장 | 빠른 적이에요. 얼음 속성이나 연사형 단어(S~Z로 시작)가 좋아요. |

## 19. 메타 성장과 해금

판이 끝나도 남는 성장은 **가볍게** 둔다. 승부를 가르는 건 단어 지식과 배치 실력이고, 메타 성장은 "조금 더 편해지는" 정도로 제한한다. 모든 영구 강화를 다 찍어도 전투력 기준 약 +10% 수준이다.

### 재화: 별

- 스테이지 별점(★1~3)이 그대로 재화가 된다. 난이도별로 따로 쌓이므로 최대 50스테이지 × 3개 × 4난이도 = **600개**.
- 같은 스테이지를 다시 깨서 별이 늘면 늘어난 만큼만 받는다.
- 도감 발견 보상과 업적으로도 별을 받는다.
- 별은 쓰더라도 별점 기록(진행도)은 줄지 않는다. "보유 별"과 "획득 별"을 따로 표시한다.

### 서재 (영구 강화)

1-10 클리어 후 열린다. 책장 모양 화면에 강화 8종이 꽂혀 있고, 별을 써서 단계를 올린다. 언제든 무료로 초기화해 다시 배분할 수 있다.

| 강화 | 단계당 효과 | 최대 | 단계별 비용 (별) |
|---|---|---|---|
| 두툼한 지갑 | 시작 골드 +5% | 5단계 (+25%) | 3 / 6 / 9 / 12 / 15 |
| 튼튼한 성벽 | 생명 +1 | 3단계 (+3) | 5 / 10 / 15 |
| 할인 계약 | 업그레이드 비용 −3% | 5단계 (−15%) | 3 / 6 / 9 / 12 / 15 |
| 반복의 미학 | 반복 할증 −1%p | 5단계 (−5%p) | 3 / 6 / 9 / 12 / 15 |
| 판매 수완 | 판매 환급 +4%p | 5단계 (60% → 80%) | 2 / 4 / 6 / 8 / 10 |
| 빠른 출발 | 조기 호출 보너스 +50% | 2단계 (×2) | 4 / 8 |
| 단어 감각 | 비슷한 단어 제안 +1개, 미발견 단어 힌트에 끝 글자 추가 | 2단계 | 5 / 10 |
| 첫 수의 여유 | 스테이지 첫 타워 건설 비용 −20% | 3단계 (−60%) | 4 / 8 / 12 |

- 전부 최대로 올리는 데 필요한 별: 246개 (최대 획득량 600개의 약 41%).
- **순수 모드**: 스테이지 시작 화면에서 켜면 서재 효과 없이 플레이한다. 무한 모드 기록은 "일반"과 "순수"를 나눠 저장한다.

### 도감 발견 보상

특수 단어를 처음 배치하면 도감에 등록된다. 발견 수에 따라 별과 꾸밈 보상을 준다. 꾸밈은 겉모습만 바꾸고 능력에는 영향이 없다.

| 조건 | 보상 |

| 특수 단어 25개 발견 | 별 5, 단어 띠 꾸밈 "양피지" |
| 50개 | 별 5, 받침대 꾸밈 "이끼 돌" |
| 100개 | 별 10, 단어 띠 꾸밈 "금박" |
| 200개 | 별 10, 받침대 꾸밈 "수정" |
| 목록 단어 전부 (지금 507개) | 별 20, 칭호 "걸어 다니는 사전", 단어 띠 꾸밈 "무지개" |

## 20. 재미 개편 v3: 공책 한 권 = 한 판 (로그라이크 런 + 전투 타이핑)

> 이 장은 8장(스테이지 모드)과 9장(무한 모드)의 진행 방식을 대신한다. 단어·속성·타워 성장·적 능력(2~7장)은 그대로 쓴다.

### 20-0. 왜 바꾸나
| 지루해지는 이유 | 해결 |
|---|---|
| 웨이브 중에 할 일이 없다 (단어 치고 구경) | **전투 타이핑**: 적 머리 위 단어를 쳐서 직접 때리고, 콤보로 타워를 강화하고, 주문 단어로 위기를 넘긴다 (20-5) |
| 매 판이 비슷하다 | **로그라이크 런**: 갈림길 지도, 쪽마다 바뀌는 규칙, 스티커(유물) 조합, 시작 펜 선택으로 판마다 빌드가 달라진다 (20-1 ~ 20-4) |
| 507개 단어를 새로 써 볼 이유가 약하다 | 쪽 규칙이 "이번엔 K 단어", "처음 쓰는 단어 할인"처럼 다른 단어를 쓰게 만들고, 적 단어로 처음 본 단어가 사전에 채워진다 |
| 한 판이 길다 (7~16웨이브 × 50스테이지) | **한 판 7~9분**. 지면 바로 다음 공책을 펼치고 싶게 만든다 |

### 20-1. 한 판의 구조
- **공책 한 권 = 한 판(런)**. 맵 한 장 위에서 진행하고, 지은 타워는 판이 끝날 때까지 남는다.
- 공책은 **7쪽**이다. 쪽을 넘길 때마다 다음 쪽을 두 갈래 중에서 고른다 (지도는 공책 목차처럼 그린 갈림길).

| 쪽 종류 | 내용 | 보상 | 비율 |
|---|---|---|---|
| 전투 | 웨이브 2개 (각 약 25초) + 쪽 규칙 1개 | 스티커 3개 중 1개 또는 골드 40 | 기본 |
| 엘리트 | 강화 적(체력 ×1.6, 무작위 강화 1개)과 긴 적 단어 | 반짝 이상 스티커 확정 + 골드 ×2 | 공책당 1~2 |
| 문구점 | 상점 (20-6) | — | 공책당 1 |
| 쉬는 시간 | 이벤트 선택지 (20-7) | 선택에 따라 | 공책당 1 |
| 보스 | 7쪽 고정. 공책 주인 보스 (6-2의 5종) | 공책 클리어, 별 | 마지막 |

- **시간 예산**: 전투 쪽 약 60초 × 4 + 엘리트 70초 + 문구점·쉬는 시간 각 20초 + 보스 약 120초 ≈ **7~9분**.
- 쪽 사이 **정비 10초** (건설·합성·판매 가능, 건너뛰기 가능). 웨이브를 일찍 부르면 남은 시간 1초당 골드 +1.
- 속도 버튼 ×1 / ×2 / ×3. 일시정지 중에는 입력을 받지 않는다.
- 시작 골드 100, 생명 20 (난이도 배율은 7장 그대로).

### 20-2. 쪽 규칙 (전투·엘리트 쪽마다 1개, 갈림길에서 미리 보임)
| 규칙 | 효과 |
|---|---|
| 모음 축제 | 모음이 3개 이상인 단어 공격력 +30% |
| 새 학기 | 이번 판에서 처음 쓰는 단어 비용 −40% |
| 받아쓰기 시험 | 적 단어 타격 피해 ×2, 오답 시 생명 −1 |
| 정전 | 모든 사거리 −20%, 빛 단어 공격력 +50% |

- 엘리트 쪽은 규칙이 2개다. 보스 쪽은 공책마다 고정 규칙 1개 (예: 금지된 도서관 = 조용히!).

### 20-5. 전투 타이핑 (웨이브 중 계속 입력)
**입력창 하나로 세 가지를 한다.** 입력창 왼쪽 아이콘이 지금 Enter를 누르면 무엇이 되는지 미리 보여 준다 (망치 = 건설, 펜촉 = 타격, 별 = 주문).

| 순서 | 조건 | 결과 |
|---|---|---|
| 1 | 주문 단어이고 잉크가 충분 | 주문 발동 |
| 2 | 칸을 골라 둔 상태 + 목록 단어 | 그 칸에 건설 (2-1 그대로) |
| 3 | 화면의 적 머리 위 단어와 같음 | 그 단어를 단 적 중 기지에 가장 가까운 적을 **타격** |
| 4 | 목록 단어지만 칸을 안 골랐음 | "칸을 먼저 골라 주세요" |
| 5 | 그 밖 | "게임에 없는 단어입니다!" (3-1) |

- **적 단어**: 모든 적이 머리 위 메모 테이프에 단어를 단다. 게임 단어 목록에서 고른다.
  - 일반 3~4글자, 빠른 적(러너·배트) 3글자, 엘리트 5~6글자, 보스는 체력 25%마다 **약점 단어**(7글자 이상)를 띄운다.
  - 같은 화면에 같은 단어는 최대 2개. 첫 글자가 겹치지 않게 고른다 (빨리 치기 좋게).
  - 처음 본 적 단어는 단어 사전에 "본 단어"로 기록된다 (철자 공개).
- **타격**: 일반 적 최대 체력의 35%, 엘리트 20%, 보스 3% (약점 단어는 12% + 진행 중인 보스 패턴 취소). 맞은 적은 0.4초 멈칫하고 새 단어를 단다.
- **콤보**: 정답 뒤 2.5초 안에 다음 정답을 내면 콤보 +1.
  - 타격 배율 `1 + 0.05 × 콤보` (최대 ×2.0). 타워 공격 속도 +1% × 콤보 (최대 +20%).
  - 오답 Enter = 콤보 0. 백스페이스는 벌점 없음.
- **잉크 게이지** (0~100): 타격 +8, 콤보 10마다 +15, 처치 +1.
- **주문 단어** (판 시작 시 2개를 고르고, 스티커·문구점으로 늘린다):

| 주문 | 잉크 | 효과 |
|---|---|---|
| STOP | 40 | 모든 적 2초 정지 (보스 1초) |
| RUSH | 30 | 모든 타워 공격 속도 +50%, 5초 |
| BOOM | 50 | 가장 적이 많은 곳에 반경 2칸 폭발 (가장 비싼 타워 공격력 ×4) |
| GOLD | 40 | 즉시 골드 +40 |
| HEAL | 60 | 생명 +3 |
| ERASE | 70 | 일반 적 1마리를 지워 없앤다 (보스·엘리트 제외) |

- **모바일**: 키보드는 설정에서 쿼티 / 천지인을 고른다 (11-5). 화면 키보드 위에 적 단어 후보 칩을 띄운다. 첫 글자를 누르면 그 글자로 시작하는 적 단어가 칩으로 뜨고, 칩을 누르면 바로 완성된다 (칩으로 낸 타격은 피해 70%).
- **접근성 옵션 "천천히 타이핑"**: 적 단어 3글자 고정, 콤보 유지 +1.5초, 오답 벌점 없음.

### 20-8. 공책 (맵)과 진행
- 기존 맵 5개가 **공책 5권**이 된다. 숲 → 초록 줄공책, 사막 → 모래색 연습장, 설원 → 하늘색 모눈공책, 화산 → 빨간 스프링노트, 도서관 → 가죽 표지 사전 노트.
- 공책마다 맵 배치 3종 중 하나가 무작위로 나온다 (기존 맵 + 변형 2종).
- 앞 공책을 클리어하면 다음 공책이 열린다.
- 기존 50스테이지는 **공책 5권 × 등급 10**으로 바뀐다. 등급 n은 쪽 규칙 외에 불리한 규칙 (n−1)개가 판 전체에 붙는다 (예: 적 체력 +10%, 정비 시간 −3초, 상점 가격 +15%…).
- 별점: 클리어 ★ / 생명 50% 이상 ★★ / 생명 손실 없음 ★★★ (8-3 그대로, 공책·등급별 기록).

### 20-9. 끝없는 공책 (무한 모드)
- 쪽이 끝나지 않는다. 10쪽마다 보스 (5종 순환, 회차마다 강화). 스티커 칸 12개.
- 점수 = 처치 점수 + 쪽 × 150 + 최고 콤보 × 20 + 처음 쓴 단어 × 50.

### 20-10. 오늘의 공책 (일일 도전)
- 날짜로 정한 같은 시드 (공책, 갈림길, 쪽 규칙, 스티커 진열이 모두에게 같음). 기록은 하루 1회.
- 결과 공유 문구: `WORD TD 오늘의 공책 11/27 · 7쪽 클리어 · 최고 콤보 34 · 많이 쓴 단어 FROST`

| 맵 (공책) | 종이 + 모눈, 형광펜 길, 입구 연필깎이 구멍, 기지 빨간 책갈피, 스티커 타워, 낙서 적 |
| 입력 카드 (회색 패널) | 모드 아이콘(건설·타격·주문), 입력 글자, 판정 미리보기, 콤보, 잉크 막대 |
| 칩 줄 | 적 단어 후보 칩, 주문 칩 |
| 키보드 | 설정에 따라 쿼티 또는 천지인 (11-5) |

### 21-6. 공격 모션과 연출 (맵 안)
| 공격 방식 | 모션 |
|---|---|
| 단일 탄환 | 연필심 탄이 날아가 꽂힌다 |
| 관통 | 자를 대고 그은 직선이 줄을 따라 지나간다 |
| 범위 | 도장이 쾅 찍히며 잉크가 튄다 (화면 살짝 흔들림) |
| 연사 | 스테이플러 심 3연발 |
| 지속 광선 | 형광펜으로 쭉 긋는 굵은 선 |
| 설치 함정 | 압정을 길에 꽂아 두고, 밟으면 튕긴다 |
| 오라 | 반짝이 가루가 원을 그리며 흩어진다 |
- 피격: 흰색 번쩍 + 지우개 가루. 처치: 지우개로 문질러 지워지고 동전이 튀어나온다.
- 타워: 흰 테두리 2px 스티커 + 마스킹테이프 단어 띠. 레벨이 오르면 테두리가 은박 → 금박 → 홀로그램.
- 치명타 숫자: 빨간 펜 동그라미. 콤보 10·20: 맵 위에 "참 잘했어요" 작은 도장.
- 쪽 클리어·공책 클리어 연출은 맵 위에 찍는 도장이고, 결과 창 자체는 회색 UI다.
- 위키 도감에서 모든 타워의 공격 모션을 미리 볼 수 있다 (카드에서 자동 재생, 누르면 상세 수치).

### 21-8. UI 부품 (기존 회색 디자인)
- 버튼: 각진 픽셀 버튼, 아래 3px 그림자, 누르면 내려감. 최소 터치 크기 48px.
- 패널·팝업: 남색 패널 + 회색 테두리. 스티커 보상·문구점 카드도 같은 패널 위에 놓는다 (스티커 그림만 컬러).
- 소리 (Web Audio 합성): 키 입력 딸깍, 타격 퍽, 도장 쿵 (범위·클리어), 지우개 슥슥 (처치), 페이지 넘김.

### 21-9. 성능 원칙
- 60fps 목표. 파티클 최대 200개, 낙서 떨림(2프레임) 효과는 초당 4번만 바꾼다.
- 종이·모눈·길은 오프스크린 캔버스에 한 번 그려 재사용한다.
- 움직임 줄이기 설정(prefers-reduced-motion)에서는 화면 흔들림과 페이지 넘김을 끈다.
